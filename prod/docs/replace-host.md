# Replace the production host

Read the [shared host-replacement planning checklist](../../shared/docs/replace-host.md).
Execution is gated until a supported guarded replacement path has been
implemented and rehearsed in staging. The routine wrappers do not support the
temporary-address sequence required by the old procedure.

Do not recreate production resources through the fresh installation guide.
Production writes require completed staging validation, the final parity audit,
and explicit approval.
